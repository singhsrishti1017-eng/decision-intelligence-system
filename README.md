# Decision Intelligence System

## Project Overview
This project analyzes profitability and shipping performance using Excel, Power BI, and Streamlit.

The system helps management:
- Predict profitable products
- Analyze shipping efficiency
- Perform scenario analysis
- Generate recommendations
- Monitor KPIs

## Tools Used
- Microsoft Excel
- Power BI
- Python
- Streamlit
- Pandas
- Plotly

## Features
- Interactive Dashboard
- Product & Region Filters
- Scenario Analysis
- Recommendation Engine
- Risk & Impact Panel

## Files Included
- app.py
- Cleaned_Data.xlsx
- PowerBI_Dashboard.pbix
- Project_Report.docx
- Presentation.pptx

## How to Run

Install dependencies:

```bash
pip install streamlit pandas openpyxl plotly
```

Run app:

```bash
streamlit run app.py
```
